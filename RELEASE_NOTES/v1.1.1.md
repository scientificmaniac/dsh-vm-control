# dsh-vm-control v1.1.1 · 首次发布到 npm

DeepSeek Harness 的 VMware 虚拟机管理插件，现在可以从 npm 官方仓库安装。本版**没有功能改动**，只是把包做成一个合格的 npm 包：补齐元数据、加发布守卫、写清发布流程。

## 安装 / Install

```bash
# 作为 npm 包安装（Node ≥ 20）
npm install dsh-vm-control

# 或作为 DSH 插件安装
dsh plugin --profile desktop install dsh-vm-control
```

安装后重启 DSH。

## 变更 / Changed

- `package.json` 补齐 npm 需要的字段：`main`、`author`、`publishConfig`（`access: public` + 官方 registry）、`engines`、`repository` / `homepage` / `bugs`。
- 新增 `prepublishOnly` 守卫：发布前自动跑版本一致性检查与语法检查，版本号、变更日志、发行说明三者不一致时 `npm publish` 直接失败。
- 新增 `PUBLISHING.md` / `PUBLISHING.zh-CN.md`：目录结构与字段说明、发布前打包验证、账号与双因素认证、`npm publish` 参数、作用域包的公开访问、发布后验证与版本更新、常见错误排查。
- `files` 白名单把新增文档纳入包内；`npm pack` 仍不含 `test/`、`scripts/`、`.github/`。

## 校验 / Verification

- 单元 53 + 接口 19 + 客户端 5 + 联动 5 = 82 项，加只读联调 8 项，全部通过。
- `npm pack` 产物 28 个条目，必需文件齐全，无测试残留；`npm publish --dry-run` 输出与之一致。

# English

The VMware control plugin for the DeepSeek Harness is now installable from the official npm registry. **No functional changes** — this release only makes the package a proper npm package: metadata, a publish guard, and the documentation of the flow.

```bash
npm install dsh-vm-control
# or
dsh plugin --profile desktop install dsh-vm-control
```

Restart DSH afterwards.

**Changed**: npm metadata (`main`, `author`, `publishConfig` with public access and the official registry, `engines`, `repository` / `homepage` / `bugs`), a `prepublishOnly` guard that runs the version/changelog/notes consistency check before publishing, and `PUBLISHING.md` / `PUBLISHING.zh-CN.md` covering layout, packing verification, accounts and 2FA, `npm publish` flags, scoped public access, post-publish verification, version bumps and troubleshooting.
