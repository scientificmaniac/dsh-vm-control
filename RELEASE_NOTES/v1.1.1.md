# dsh-vm-control v1.1.1

一次只动打包元数据的补丁版本，**没有功能改动**：为 `package.json` 补上 `main`（给不认 `exports` 的工具兜底）与 `author` 两个字段。

## 安装

```bash
dsh plugin --profile desktop install dsh-vm-control
# 或在仓库目录里
dsh plugin --profile desktop install .
```

安装后重启 DSH。

## 验证

出包前跑过：单元 53 + 接口 19 + 客户端 5 + 联动 5，加只读联调 8 项，全部通过；`npm pack` 产物文件清单与会话中逐条核对一致。
